# Five-minute demo script

1. State the boundary: practice coaching, no hiring recommendation, cues never alter content scores.
2. Show `/health` or the Setup model-status panel so degraded/real components are explicit.
3. Load the sample resume and JD and start a two-question interview.
4. Open the retrieved evidence IDs, dense/lexical scores, support method, and runtime provenance.
5. Submit a vague answer and show the deterministic clarification rule.
6. Submit a specific technical claim and show the probe plus independent scorecard.
7. Correct a transcript and re-evaluate it.
8. Finish and download the report; point out trends rather than an employability score.
9. Close with the frozen synthetic v1 result: Recall@3 100%, MRR 0.925, schema/citation validity 100%,
   3/3 strong-over-weak score ordering, score-band accuracy 66.7%, and 13.36/29.07-second median/p95
   generation latency.
